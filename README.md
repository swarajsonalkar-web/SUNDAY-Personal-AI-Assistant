# SUNDAY — Personal AI Assistant
FastAPI + SQLite local-first MVP: tasks, notes and a rule-based assistant demo (not a connected generative AI model).
Run: `python -m venv .venv`, activate it, `pip install -r requirements.txt`, then `uvicorn app:app --reload --port 8001`.
Open http://127.0.0.1:8001. Database is created automatically. Add authentication before multi-user use.
